# Script_analisi_qualitativa

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)]()

## Descrizione
Script Python per l'analisi qualitativa di dati geologici e geomorfologici con strumenti di classificazione, valutazione e interpretazione di parametri qualitativi. Genera report e visualizzazioni analitiche.

## Installazione e uso rapido
1. Clonare il repository:
   ```bash
   git clone https://github.com/DarioCiampalini/Script_analisi_qualitativa.git
   cd Script_analisi_qualitativa
   ```
2. Eseguire lo script principale:
   ```bash
   python script.py
   ```

## Output
- Dati classificati in formato CSV
- Grafici e visualizzazioni in PNG
- Report analitici con interpretazioni qualitative
